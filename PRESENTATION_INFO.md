## 🚀 How to Use

### Local Development
1. Open `index.html` directly in a modern web browser
2. Use arrow keys or space bar to navigate
3. Press 'S' for speaker notes
4. Press 'F' for fullscreen
5. Press 'ESC' for slide overview

### Keyboard Shortcuts
- **→ / Space / Enter**: Next slide
- **← **: Previous slide
- **↑ / ↓ **: Navigate vertical slides
- **ESC**: Slide overview
- **S**: Speaker notes
- **F**: Fullscreen
- **B**: Blackout

### Deploy to GitHub Pages
1. Create a new GitHub repository
2. Push the `index.html` file to the repository
3. Go to Settings → Pages
4. Select the main branch as source
5. Your presentation will be live at: `https://username.github.io/repo-name/`

## 💡 Customization Tips
1. **Colors**: Edit CSS variables in the `<style>` section
   - `--primary-purple`: Main purple color
   - `--primary-teal`: Main teal color
   - `--accent-pink`: Accent color
2. **Transitions**: Modify `transition` in `Reveal.initialize()`
3. **Timing**: Adjust `transitionSpeed` for faster/slower animations
4. **Size**: Change `width` and `height` in configuration
