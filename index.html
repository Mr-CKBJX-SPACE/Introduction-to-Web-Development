Introduction to Web Development

Understanding the Digital Landscape 🌐

What is Web Development?

  • The process of creating websites and web applications
  • Combines design, programming, and database management
  • Powers everything from simple blogs to complex platforms
  • Constantly evolving with new technologies and frameworks
  • Essential skill in today's digital economy
Web development is the backbone of the internet. It encompasses everything from the pages you view to the applications you use daily.

Frontend vs Backend vs Full Stack

  • HTML, CSS, JavaScript

⚙️ Backend

🔄 Full Stack

How the Web Works

Client-Server Model

  • Client (Browser): Requests resources
  • Server: Processes requests and sends responses
  • HTTP/HTTPS: Communication protocol
  • DNS: Translates domain names to IP addresses
  • Response: HTML, CSS, JS, images, data
Understanding the client-server model is fundamental. Every web interaction follows this pattern.

Web Development Tools & Environment Setup

  • Code Editor: VS Code, Sublime Text, Atom
  • Browser: Chrome DevTools, Firefox Developer Tools
  • Version Control: Git & GitHub
  • Package Managers: npm, yarn
  • Local Server: Live Server, Python SimpleHTTPServer
💡 Pro Tip: VS Code with extensions like Live Server, Prettier, and ESLint is the most popular setup for web development.

HTML5

The Structure of the Web 📄

What is HTML?

  • HTML: HyperText Markup Language
  • Standard markup language for web pages
  • Uses tags to structure content
  • HTML5 is the latest version with modern features
  • Works together with CSS and JavaScript
💡 Remember: HTML provides structure, CSS provides style, JavaScript provides behavior.

Semantic HTML5 Elements

  • <header>: Page or section header
  • <nav>: Navigation links
  • <main>: Main content
  • <article>: Independent, self-contained content
  • <section>: Thematic grouping of content
  • <aside>: Sidebar content
  • <footer>: Page or section footer
  • <figure> & <figcaption>: Images with captions

Benefits: Better SEO, accessibility, and code readability! ✨

Forms and Input Types

HTML5 APIs

  • Geolocation API: Access user's location
  • Canvas API: Draw graphics dynamically
  • Drag and Drop API: Interactive drag/drop
  • Web Storage API: localStorage & sessionStorage
  • Audio/Video API: Native media playback
  • Web Workers: Background JavaScript execution

HTML Best Practices

  • Always use semantic HTML elements
  • Include proper DOCTYPE and meta tags
  • Add alt attributes to images for accessibility
  • Use meaningful IDs and class names
  • Keep code properly indented and organized
  • Validate your HTML using W3C validator
  • Make your site accessible (ARIA attributes)

CSS3

Making the Web Beautiful 🎨

What is CSS?

  • CSS: Cascading Style Sheets
  • Controls the visual presentation of HTML
  • Separates content from design
  • CSS3 adds animations, gradients, and more
  • Enables responsive design for all devices

CSS Selectors and Specificity


/* Element Selector */
p { color: blue; }

/* Class Selector */
.highlight { background-color: yellow; }

/* ID Selector */
#header { font-size: 24px; }

/* Descendant Selector */
nav a { text-decoration: none; }

/* Pseudo-class */
a:hover { color: red; }

/* Attribute Selector */
input[type="email"] { border: 2px solid green; }
💡 Specificity: Inline > ID > Class > Element

The Box Model


.box {
    /* Content */
    width: 300px;
    height: 200px;
    
    /* Padding - space inside the border */
    padding: 20px;
    
    /* Border */
    border: 2px solid #333;
    
    /* Margin - space outside the border */
    margin: 10px;
    
    /* Box-sizing changes how width/height are calculated */
    box-sizing: border-box;
}

Total width = width + padding + border + margin

Flexbox Layout


.container {
    display: flex;
    flex-direction: row; /* or column */
    justify-content: space-between; /* main axis */
    align-items: center; /* cross axis */
    flex-wrap: wrap;
    gap: 20px;
}

.item {
    flex: 1; /* grow, shrink, basis */
    flex-grow: 1;
    flex-shrink: 0;
    flex-basis: 200px;
}

Perfect for one-dimensional layouts! 📏

Grid Layout


.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: auto;
    gap: 20px;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

Ideal for two-dimensional layouts! 📐

CSS3 Features: Transitions, Animations, Transforms


/* Transition */
.button {
    transition: all 0.3s ease;
}
.button:hover {
    transform: scale(1.1);
    background-color: #ff6b6b;
}

/* Animation */
@keyframes slideIn {
    from { transform: translateX(-100%); }
    to { transform: translateX(0); }
}

.animate {
    animation: slideIn 1s ease-in-out;
}

/* Transform */
.rotate { transform: rotate(45deg); }

Responsive Design Principles

  • Mobile-First: Design for small screens first
  • Fluid Grids: Use percentages instead of fixed widths
  • Flexible Images: max-width: 100%
  • Media Queries: Breakpoints for different devices
  • Viewport Meta Tag: Control mobile rendering
  • Relative Units: em, rem, vw, vh

Media Queries


/* Mobile First Approach */
.container {
    width: 100%;
    padding: 10px;
}

/* Tablet */
@media (min-width: 768px) {
    .container {
        width: 750px;
        padding: 20px;
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        width: 960px;
    }
}

/* Large Desktop */
@media (min-width: 1200px) {
    .container {
        width: 1140px;
    }
}

GitHub

Version Control & Collaboration 🔧

What is Version Control?

  • Track changes to code over time
  • Collaborate with multiple developers
  • Revert to previous versions if needed
  • Branch for features and experiments
  • Essential for professional development

Git vs GitHub

📦 Git

  • Version control system
  • Local repositories
  • Command-line tool
  • Created by Linus Torvalds

🐙 GitHub

  • Web-based hosting service
  • Remote repositories
  • Collaboration features
  • Community & open source

Creating Repositories

  • Click "New Repository" on GitHub
  • Choose a descriptive name
  • Add a README.md file
  • Select a license (MIT, Apache, GPL)
  • Clone to your local machine
💡 Tip: Use a .gitignore file to exclude files like node_modules, .env

Basic Git Commands


# Initialize a repository
git init

# Clone a repository
git clone https://github.com/username/repo.git

# Check status
git status

# Stage files
git add .
git add filename.html

# Commit changes
git commit -m "Add new feature"

# Push to remote
git push origin main

# Pull latest changes
git pull origin main

# Create and switch to a branch
git checkout -b feature-branch

GitHub Pages Setup

  • Go to repository Settings
  • Navigate to "Pages" section
  • Select source branch (usually main)
  • Choose root or /docs folder
  • Save and wait for deployment
  • Access at: username.github.io/repo-name

Deploying Your First Website

Step-by-Step Deployment

  1. Create index.html with your web page
  2. Create a new GitHub repository
  3. Push your code to the repository
  4. Enable GitHub Pages in settings
  5. Visit your live website!

🎉 Congratulations! You're now a published web developer!
